⚖️ Executive Summary & Legal Framework

Under Revenue Regulations (RR) No. 8-2022, RR No. 9-2021, and the Ease of Paying Taxes Act (RA 11976), covered Philippine taxpayers are required to issue electronic invoices and transmit sales data to the Bureau of Internal Revenue Electronic Invoicing System (BIR EIS). This proposal outlines the deployment of a dedicated desktop middleware connecting your QuickBooks Desktop software to the BIR EIS Gateway without disrupting your operational workflows.

1 System Compliance Deliverables (Documentation Package)

To support your official Permit to Use (PTU) / Permit to Transmit (PTI/PTT) / CAS Accreditation application with the assigned Revenue District Office (RDO) / Large Taxpayers Service (LTS), the following complete technical binder is provided:

  • Software Identity & Specification Document: Comprehensive documentation of the middleware architecture, runtime profile (Tauri v2 + Rust backend + SQLite cache), and QuickBooks COM SDK connector.
  • System Architecture & Data Flow Diagram: Visual diagrams detailing transaction flow from QuickBooks company files (.QBW) through local validation, SHA-256 hashing, and HTTPS transmission to the BIR EIS Gateway.
  • BIR JSON Schema Specifications & Payload Mapping: Itemized field mapping between QuickBooks invoice records and the canonical BIR EIS JSON schema format.
  • Audit Trail, Security Protocols, and Data Immutability Specifications:
    • SHA-256 digital payload signature generation for tamper-proof compliance.
    • Immutable chronological CAS audit logging tracking all creation, modification, and transmission events.
    • Local archival in Microsoft Access (.accdb) / SQLite database formats.
  • User Operation and System Administration Manual: End-to-end visual operational guide covering initial setup, QuickBooks syncing, tax code mapping, invoice printing, and transmission.

2 Core Middleware Functional Modules

Module Description & Technical Capabilities
1. QuickBooks COM Bridge Direct Windows COM / QBXML bridge extracting invoices, customer profiles, items, and tax rates without manual CSV export/import steps.
2. BIR EIS Tax Engine Automated tax calculation engine supporting:
• 12% VATable Sales (Gross / 1.12) & Output VAT (12%)
• 0% VAT-Exempt & Zero-Rated Sales (Direct Exports / PEZA)
• Senior Citizen & PWD 20% statutory discount + VAT exemption
• Creditable Withholding Tax (BIR Form 2307: 1% Goods / 2% Services)
3. EIS API Gateway Transceiver Automated batch JSON packaging, SHA-256 digital signature computation, and secure HTTPS transmission with official BIR Acknowledgement Numbers (EIS-ACK).
4. CAS Print & PDF Engine Multi-page synchronized continuous and A4 printing with mandatory BIR CAS accreditation footer and scannable verification QR codes.
5. MS Access Exporter 1-click automated synchronization with local MS Access (.accdb) databases for offline audit readiness.

3 Implementation & Certification Scope

  • Phase 1: Middleware Deployment & QuickBooks Field Mapping
    Deploy desktop middleware on client workstations; connect to live QuickBooks company file; configure BIR Form 2303 profile and map sales tax codes (TAX, NON, ZERO, SENIOR, EWT).
  • Phase 2: EIS Portal Registration & API Credential Configuration
    Assist client in enrolling with the BIR EIS Developer Portal; configure API Client ID, Client Secret, and Gateway Endpoints (Sandbox vs. Production).
  • Phase 3: EIS Sandbox Testing & Mandatory Scenario Execution
    Execute all mandated BIR test transaction scenarios (Standard VAT, Exempt, Zero-Rated, Senior/PWD, Withholding Tax); collect JSON logs, payload hashes, and EIS-ACK receipts for the BIR evaluation team.
  • Phase 4: PTI/PTT Application Dossier Preparation & Technical Demo
    Compile complete RDO accreditation binder; provide technical demonstration support during BIR evaluation; switch middleware to live Production mode upon permit issuance.
  • Phase 5: Staff Training & Post-Implementation Warranty
    Conduct hands-on training for accounting and IT personnel; provide 30-day post-go-live stabilization warranty for updates and schema support.
